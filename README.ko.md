# 박주형 (Joohyeong Park)

충북대학교 지능로봇공학과 학부 4학년이며 SUV LAB 소속입니다. 석사과정에 진학할 예정이고, 2028년 항공우주·방산 분야 연구개발(R&D) 취업을 목표로 하고 있습니다.

## 관심 분야

- **군집 궤적 계획** — 드론쇼에서 여러 드론이 다음 형상으로 이동할 때, 충돌 없이 최소 시간에 끝나는 형상 전환 궤적을 비행 전에 생성하는 알고리즘을 연구합니다.
- **다중 드론 비행 시스템** — PX4와 GPS-RTK를 활용한 다중 드론 라이트쇼에서 궤적 생성, 비행 안전성 검증과 실비행을 경험했습니다. 팀 단위로 최대 36대 규모의 실비행을 했습니다.
- **온라인 군집 탐색** — 다중 드론이 동적 환경에서 탐색하고 경로를 계획하는 공동연구에 참여하고 있습니다.

주로 쓰는 기술: C / C++, Python, ROS2, PX4, PX4 SITL, Gazebo, GPS-RTK, Git, Linux
